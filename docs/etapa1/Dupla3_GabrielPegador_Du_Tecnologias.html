Tarefa 3 — Escolher o Banco de Dados

O banco de dados é onde ficam guardadas todas as informações do app (usuários, aulas, partidas, etc.).

Existem dois grandes tipos:

  • Relacional (SQL): dados organizados em tabelas com linhas e colunas, com relacionamentos entre elas (ex.: PostgreSQL, MySQL)
  • Não-relacional (NoSQL): dados guardados como documentos flexíveis, sem esquema fixo (ex.: MongoDB, Firebase Firestore)
Pesquisem pelo menos 2 opções de banco, comparem e justifiquem. Pensem: os dados do nosso app têm muitos relacionamentos entre si (professor-aluno, aula-presença, partida-jogadores)?

Tarefa 4 — Modelo Entidade-Relacionamento (DER)

O que é: O DER é o "mapa" do banco de dados. Ele mostra todas as tabelas (entidades), seus campos (atributos) e como elas se conectam (relacionamentos).

Como fazer:

  1. Identifiquem as entidades (ex.: Usuário, Aula, Partida...)
  2. Para cada entidade, listem os campos necessários (nome, tipo, se é obrigatório)
  3. Definam os relacionamentos entre elas (1:1, 1:N, N:N)
  4. Identifiquem as chaves primárias (PK) e chaves estrangeiras (FK)
Exemplo — 1 entidade para vocês entenderem o formato
USUARIO

Descrição: Armazena todos os usuários do sistema.

CampoTipoRestriçãoDescrição
idUUIDPKIdentificador único
nomeVARCHAR(100)NOT NULLNome completo
emailVARCHAR(150)UNIQUE, NOT NULLE-mail para login
.........Que outros campos um usuário precisa ter?
Agora identifiquem TODAS as entidades que o app precisa e detalhem cada uma como no exemplo acima. Olhem os requisitos do Biel & Túlio: cada "coisa" que o sistema armazena provavelmente é uma tabela.
Perguntas para descobrir as entidades:
— O sistema armazena dados de quem? (professores, alunos... são a mesma tabela ou tabelas separadas?)
— O professor cria "grupos" de alunos — precisa de uma tabela para isso?
— As aulas são guardadas onde? Quais dados de uma aula precisam ser salvos?
— O aluno confirma presença — essa informação fica na tabela de aula ou em uma tabela separada?
— A avaliação de desempenho é guardada onde? Que campos ela tem?
— As partidas entre alunos — quais dados precisam ser registrados?
— Se um aluno pode pertencer a vários grupos, como vocês resolvem esse relacionamento N:N? (Dica: pesquisem "tabela associativa" ou "tabela pivô")
— Quais tabelas se conectam com quais? Desenhem setas.
